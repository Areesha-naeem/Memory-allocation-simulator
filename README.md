# memory-allocation-simulator
A Python-based Memory Allocation Simulator that demonstrates the First Fit, Best Fit, and Worst Fit memory allocation algorithms. The project features a Tkinter-based graphical user interface where users can enter memory blocks and processes, execute different allocation strategies, and compare the allocation results.

## Technologies Used
- Python
- Tkinter

## Files
- `memory_allocation.py` – Source code and GUI
- `Project_Report.pdf` – Project report with screenshots and documentation
